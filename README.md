## দ্রুত শুরু

### প্রয়োজনীয়তা
- কোনো সার্ভার-সাইড ডিপেন্ডেন্সি নেই
- যেকোনো আধুনিক ওয়েব ব্রাউজার
- স্থানীয় সার্ভার (ঐচ্ছিক, CORS এর জন্য)

### ইনস্টলেশন

```bash
# রিপোজিটরি ক্লোন করুন
git clone https://github.com/kajalvai0/Ether-.git
cd Ether-

# একটি স্থানীয় সার্ভার শুরু করুন (Python)
python -m http.server 8000

# বা Node.js এর সাথে
npx http-server

# ব্রাউজার খুলুন এবং দেখুন
open http://localhost:8000
```

### গিটহাব পেজ ডিপ্লয়মেন্ট

রিপোজিটরি সেটিংস → Pages → Source = main branch

## ডেভেলপার গাইড

### ফাইল সম্পাদনা

**HTML পরিবর্তন** (`index.html`)
- সমস্ত সামগ্রী একটি একক ফাইলে রয়েছে (SPA)
- সেকশন ID: `#home`, `#about`, `#courses`, `#achievements`, `#contact`

**স্টাইলিং** (`style.css`)
- CSS কাস্টম প্রপার্টি ব্যবহার করুন (রঙ পরিবর্তনের জন্য)
- মোবাইল-প্রথম পদ্ধতি অনুসরণ করুন
- 768px এ মিডিয়া কোয়েরি ব্রেকপয়েন্ট

**স্ক্রিপ্ট** (`script.js`)
- সরল DOM ম্যানিপুলেশন
- ক্লিক ইভেন্ট হ্যান্ডলিং নেভিগেশনের জন্য
- কোনো বাহ্যিক ফ্রেমওয়ার্ক নেই (Vanilla JS)

## সমস্যা সমাধান

### সাধারণ সমস্যা

**Q: ইমেজ লোড হচ্ছে না**
- A: `ethagorus.jpg` রুট ডিরেক্টরিতে রয়েছে কিনা চেক করুন
- পথ সামঞ্জস্য: `src="ethagorus.jpg"` বা `src="/ethagorus.jpg"`

**Q: বাংলা ফন্ট সঠিকভাবে প্রদর্শিত হচ্ছে না**
- A: ব্রাউজার ক্যাশ ক্লিয়ার করুন (Ctrl+Shift+Del)
- ফন্ট সমর্থন চেক করুন CSS-তে

**Q: পেজ স্যুইচিং কাজ করছে না**
- A: JavaScript সক্ষম আছে কিনা চেক করুন
- ব্রাউজার কনসোলে ত্রুটি দেখুন (F12)

**Q: মোবাইলে নেভিগেশন ভাঙা দেখাচ্ছে**
- A: Viewport meta ট্যাগ চেক করুন (উপস্থিত থাকবে)
- ডিভাইস ডিবাগিং চেষ্টা করুন
